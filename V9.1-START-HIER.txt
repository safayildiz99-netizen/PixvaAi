YILDIZ AI V9.1 – ALTE OBERFLÄCHE + SCHRIFT ERSETZEN + PAYPAL
================================================================

WAS DIESES UPDATE MACHT
-----------------------
- Stellt automatisch exakt die funktionierende V9-Oberfläche wieder her.
- Dein alter Admin-Login und alle V9-Konten bleiben erhalten.
- Fügt „Schrift im KI-Bild ändern“ hinzu.
- Fügt echte PayPal-Zahlungen hinzu.
- Der Admin kann Zahlungen ein- oder ausschalten.
- Preise können sichtbar bleiben, obwohl ein Abo nicht kaufbar ist.
- Das Geld geht an das PayPal-Business-Konto, dessen API-Zugang in Vercel eingetragen ist.

WICHTIG ZUR SCHRIFT
-------------------
Text, der von einer Bild-KI direkt in ein Bild gezeichnet wurde, besteht nur aus Pixeln.
Darum kann die alte Schrift nicht wie eine normale Textebene umgestellt werden.
V9.1 löst das so:
1. „Schriftbereich markieren“ drücken.
2. Gelben Rahmen über die alte Schrift ziehen.
3. Neuen Text, Schriftart, Größe und Farbe einstellen.
4. „Schrift ersetzen“ drücken.
5. Der neue Text ist danach eine echte Ebene und jederzeit bearbeitbar.

INSTALLATION – EINFACHER WEG
----------------------------
1. Den Inhalt dieses ZIPs in die Hauptseite deines GitHub-Projekts hochladen.
2. GitHub oben auf „Actions“ öffnen.
3. Links „Yildiz AI V9.1 installieren“ wählen.
4. „Run workflow“ und nochmals „Run workflow“ drücken.
5. Der Workflow stellt die originale V9 wieder her, ergänzt nur dieses Update,
   prüft den Build und veröffentlicht den neuen Commit automatisch.
6. In Vercel warten, bis Ready + Production erscheint.

SUPABASE
--------
1. V9.1-SUPABASE-EINFACH-OEFFNEN.html doppelklicken.
2. „Alles kopieren“ drücken.
3. Supabase → SQL Editor → New query.
4. Einfügen → Run.
5. Am Ende muss stehen:
   Yildiz AI V9.1 PayPal und bezahlte Zugänge erfolgreich installiert.
