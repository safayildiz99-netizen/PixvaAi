YILDIZ AI V10.0.4 – LOGIN-FIX
================================

DIESER FIX ÄNDERT NUR DEN LOGIN
-------------------------------
- Anmeldung funktioniert mit Benutzername oder E-Mail.
- Der Benutzername „admin“ funktioniert nach einmaliger Einrichtung.
- Das Passwort wird sicher über Supabase Auth geprüft.
- Der Vercel-Hobby-Plan bleibt bei nur einer Serverless Function.
- Andere V10-Funktionen und die bestehende Oberfläche werden nicht entfernt.

INSTALLATION
------------
1. Diese ZIP entpacken.
2. Den gesamten Inhalt in dein GitHub-Projekt hochladen.
3. Vorhandene Dateien ersetzen.
4. Commit-Nachricht:
   Yildiz AI V10.0.4 Login mit admin repariert
5. In Vercel warten, bis das Deployment „Ready“ ist.

ADMIN EINMAL EINRICHTEN
-----------------------
1. Vercel → Settings → Environment Variables.
2. Neue Variable anlegen:
   Name: ADMIN_SETUP_SECRET
   Wert: ein eigenes geheimes Passwort mit mindestens 16 Zeichen
   Environment: Production
3. Neues Deployment starten.
4. Diese Seite öffnen:
   https://DEINE-DOMAIN/admin-login-einrichten.html
5. Dort eintragen:
   - dasselbe geheime Setup-Passwort
   - deine Admin-E-Mail
   - dein gewünschtes Admin-Passwort
6. „Admin einrichten“ drücken.
7. Danach auf der normalen Loginseite anmelden:
   Benutzername: admin
   Passwort: das von dir gerade festgelegte Passwort
8. WICHTIG: ADMIN_SETUP_SECRET anschließend wieder aus Vercel löschen.

Du kannst als neues Admin-Passwort erneut „SafaStart2026!“ verwenden, sofern du
genau dieses Passwort wieder benutzen möchtest.

SICHERHEIT
----------
Die Admin-Einrichtung ist ohne ADMIN_SETUP_SECRET vollständig gesperrt.
Das Setup-Passwort gehört niemals in GitHub.
