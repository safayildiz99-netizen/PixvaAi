- Alles markieren und kopieren.
- Supabase -> SQL Editor -> New query.
- Code einfügen und Run drücken.

2. GITHUB
- ZIP entpacken.
- Den INHALT des entpackten Ordners in die Hauptseite deines GitHub-Repositories hochladen.
- Vorhandene Dateien ersetzen.
- Den äußeren Ordner nicht als neuen Unterordner hochladen.
