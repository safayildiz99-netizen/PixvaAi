YILDIZ AI – PRIVATE KONTEN UND CLOUD-SYNCHRONISIERUNG

Warum vorher alle Konten dieselben Chats sahen:
Die Chats wurden nur im Browser unter einem gemeinsamen Schlüssel gespeichert. Deshalb teilten Admin und Mitarbeiter auf demselben Gerät denselben Verlauf. Auf einem anderen Gerät fehlten die Chats vollständig.

Neu:
- Jedes Konto hat einen eigenen privaten Chat-Speicher in Supabase.
- Derselbe Account lädt auf jedem Gerät denselben Chat-Verlauf.
- Beim Account-Wechsel wird der Chat vollständig neu geladen.
- Gast-Chats bleiben nur lokal auf dem jeweiligen Gerät.
- Projekte sind ebenfalls nur noch für ihren Besitzer sichtbar. Admins verwalten Konten, sehen aber keine fremden Projekte.
- Es gibt weiterhin eine lokale Sicherung, falls die Internetverbindung kurz ausfällt.

WICHTIG – ZUERST SQL:
1. Supabase öffnen.
2. SQL Editor öffnen.
3. Neue Query erstellen.
4. Den vollständigen Inhalt aus KONTO-CLOUD-SYNC.sql einfügen.
5. Run drücken.

DANACH GITHUB:
